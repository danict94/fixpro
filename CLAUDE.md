# Bootstrap CLAUDE.md

Questo file e solo il bootstrap shim del repository.

## Ordine obbligatorio di lettura

Prima di qualsiasi analisi, piano, modifica file o scrittura codice:

1. Leggi `docs/CLAUDE.md` per la governance primaria del progetto.
2. Leggi `docs/ROADMAP.md` per stato reale, blocchi e avanzamento.
3. Se il task tocca catalogo, matching, SEO, form richiesta, profili impresa, pricing/admin logic, settori, categorie o servizi, leggi anche `docs/Taxonomy.md`.
4. Solo dopo puoi valutare il task.

## Regole bootstrap

- `docs/CLAUDE.md` e la fonte primaria di governance. Se un altro file dice qualcosa di diverso, prevale `docs/CLAUDE.md`.
- `docs/ROADMAP.md` descrive stato prodotto, blocker P0/P1 e criteri per aggiornare gli stati.
- Nessuna mutazione e nessuna proposta implementativa finale prima di aver letto i file sopra.
- Dopo la lettura devi sempre riassumere:
  - blocker P0/P1 rilevanti
  - vincoli operativi rilevanti
  - file probabili da toccare
  - rischi principali
- Ogni intervento richiede preflight esplicito e conferma utente: `OK PROCEDI`.
- Se manca `docs/CLAUDE.md` o `docs/ROADMAP.md`, fermati e dichiaralo esplicitamente.
- Se il task tocca il dominio catalogo e manca `docs/Taxonomy.md`, fermati e dichiaralo esplicitamente.

## Nota

Questo file non contiene regole di dominio, checklist operative, policy di sicurezza o stati roadmap dettagliati.
Quelle regole vivono in `docs/CLAUDE.md` e `docs/ROADMAP.md`.
